# Archive Studio 游戏赛季封面替换

## 目标

通过 Archive Studio 的受控维护链路替换既有 Games 赛季封面，并由公开数据同步流程生成网页规格图片。不得直接覆盖 `public` 中的展示文件。

## 本次范围

- 目标：既有 `live_game` 下的一个赛季封面。
- 输入：用户明确选择的本地图片。
- 源侧：只替换 Archive 中该赛季的 `cover` 文件。
- 展示侧：通过 Games 同步预览、令牌和应用流程更新 `games.json` 并生成 WebP。
- 旧 Data：只读核对，必须保持不变。

## 安全与回退

- 替换前运行 Games v2 结构基线。
- 在 Archive 的事务目录保存旧封面副本及 preview / write / rollback 记录。
- 源图写入后再次运行结构检查并核对旧 Data 元数据。
- 网站同步失败时，Archive 源图和待同步标记仍保留，可重试；不得手工覆盖公开图片。
- 如需回退，按事务 `rollback.json` 将备份封面恢复到原相对位置，再重新运行公开同步。

## 验收

- Archive 目标赛季只有一个有效封面文件。
- Games v2 结构检查通过，赛季数量不变。
- 公开同步后目标赛季引用新的 `studio_media` 图片。
- 公开图片经过 Games 封面配置处理，尺寸为 600 x 900 WebP。
- `public/data/games.json` 总数和赛季总数不因替换而变化。
- 旧 Data 无变化，不运行 `build_archive.py`，不发布，不执行 Git 写操作。
